# finhub-ops-pack

Five skills and four agents adapted from harness-100 (Apache-2.0, commit 8e8d35c). Install as a Claude plugin.

| Part | Skills | Agents |
|---|---|---|
| Data pipeline | data-quality-framework, dag-orchestration-patterns | data-quality-manager, pipeline-reviewer |
| Chatbot | intent-taxonomy-builder, conversation-flow-validator | conversation-designer, dialog-tester |
| Licensing | license-compatibility-matrix | none |

Limits: these are generic methods. They are not wired to Mercury, Twilio or Google Workspace, and nothing here was tested against a live connector. The licence matrix is general guidance, not legal advice. Anything a client will read is a draft for Daniel to approve.
