# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please open a private GitHub security advisory on this repository (Security tab, "Report a vulnerability").

Please include:

- A description of the issue
- Steps to reproduce
- Potential impact

We aim to acknowledge reports within 7 days and to provide a resolution timeline as soon as the issue is confirmed.

Do not open a public issue for security vulnerabilities.
