## Gaps

- No agent loop, context compaction or step logic in-tree for the classic app path: the dify-agent runtime delegates to pydantic-ai and `pydantic_ai_harness` (external packages), and workflow DAG execution is the external `graphon` package. Searched: `class .*Engine`, `graph_engine`. Slices 1, 2 and 5 evidence is the wrapper code only.
- No retrospective or learning loop that feeds results back into prompts (searched: `evolve`, `retrospect`, `reflection`, `lesson` across `api/core` and `dify-agent/src`).
- No judge panel or multi-reviewer consensus. The only review rules are `.agents/skills/backend-code-review`; the three other skills are frontend and e2e (not opened).
- No memory or session-ledger design beyond `api/core/memory/token_buffer_memory.py` (chat history window, not opened past its imports) and the snapshot store `agent_v2/session_store.py` (listed, not read).
- MCP server side (`api/core/mcp/server`) and auth (`core/mcp/auth`) were not opened; MCP client is already adopted (see above).
- Ask-human tool schema (`layers/ask_human/schema.py`, `configs.py`) and `runtime/compositor_factory.py` were not read.
